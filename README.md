# FOOTBASE (BETA)
Footbase is a Python-based CLI application designed to search for football (soccer) players and provide detailed information about them. It offers an easy and convenient way to explore player profiles directly from the command line.

## Setup
1. Clone the repository
```sh
git clone https://github.com/gordonchis1/footbase
cd footbase
```
3. Install the package
```sh
pip install .
```

## Example
```sh
footbase search messi
```
